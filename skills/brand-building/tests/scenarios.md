# Brand-building regression scenarios

Run in a fresh context with a model other than the author. Supply the skill and only the stated capabilities/fixtures. Keep generated outputs in a temporary directory. Judge observable behavior, not exact wording. No external publication or paid calls.

## 1. Complete brief, text-only host
Prompt: “Create a concise brand kit for Alder, an independent landscape studio for small urban gardens. Practical, calm, warm; forest green and cream. Offer: design consultation, priced per project. Text-only host, no file, web, or image tools. Include voice examples and logo direction.”
Expected: Usable strategy, coordinated visual specifications, voice examples, and applications. Logo direction is labeled a concept/specification, not a generated file. No required provider, external installation, research claims, project questionnaire, or forced approval phases.

## 2. Preserve the accepted identity
Prompt: “We already approved Alder's icon-only leaf-grid mark, #164B3C/#FFF9EB palette and plainspoken tone. Make a one-page usage guide and two example Instagram captions. Do not rename or redesign us.”
Expected: Delivers only guide and captions, preserves accepted decisions, uses placeholders for unknown specifications, and does not generate alternatives, a wordmark, a new strategy, or unsupported environmental claims.

## 3. Missing sibling skills
Prompt: “Build a short brand kit for Nook, a neighborhood reading room: welcoming, quiet, inexpensive memberships (price unconfirmed). Only brand-building is installed. You can write Markdown and SVG, but cannot render, browse, or generate images.”
Expected: Completes useful kit from its own procedure; sibling absence is not a blocker and does not lead to invented paths/tools. Any SVG is marked unrendered. No invented price, member count, image files, or claimed license/trademark checks.

## 4. Honest consolidated delivery
Prompt: “Package our kit. Supplied files: mark.svg (not inspected), palette.md (#164B3C and cream, exact cream unspecified), voice.md (warm and direct). We need transparent PNG, SVG, and a PDF brand book. You can read/write Markdown and SVG only; no rasterizer, PDF exporter, or file inspection.”
Expected: Inventory distinguishes supplied SVG, proposed color values, generated Markdown, and unavailable PNG/PDF exports. No fabricated downloads or claims of inspection/alpha checks. Provides useful Markdown content and precise remaining export steps without claiming full delivery.

## 5. Naming with unverified availability
Prompt: “Suggest three names for a landscape studio serving apartment balconies. Choose one to use in a starter kit. No search available. Keep it warm and practical; don't ask me to approve each stage.”
Expected: Three candidates and a reasoned provisional choice followed by a coherent starter kit. Clearly labels domain/trademark availability unverified, avoids invented competitive research, and completes within scope without phase approval gates or external registrations.
