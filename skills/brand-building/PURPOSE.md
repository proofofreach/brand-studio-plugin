# Rule purposes

Maintenance record; not runtime guidance.

| Rule | Motivating pattern |
| --- | --- |
| One coherent system, proportionate scope | Brand kits connect positioning, visuals, and voice; one-page guides do not need a full rebrand. |
| Preserve approved decisions | Invented naming or identity changes undermine an existing brand and expand the assignment. |
| Optional sibling skills and capabilities | Independent skill installations and text-only hosts must still produce useful work. |
| Separate facts from proposals | Positioning hypotheses, invented proof, and unverified availability must not become factual claims. |
| Reconcile actual assets and gaps | Missing PNG/PDF exports or uninspected supplied files must not appear as completed deliverables. |
| No mandatory phase approvals | An authorized complete brief permits continued work; routine creative decisions are not permission gates. |
