# Rule purposes

Maintenance record; not runtime guidance.

| Rule | Motivating pattern |
| --- | --- |
| Evidence before specificity | Precise but invented numbers, proof, offer terms, and deadlines make persuasive copy false. |
| Adapt awareness and structure to the task | Awareness, AIDA/PAS, and Seven Sweeps help decisions; a small brief should not trigger a full campaign. |
| Capability-driven evidence access | Text-only hosts can draft from a brief; inaccessible URLs cannot support page-specific findings. |
| References loaded on demand | Large libraries improve specific work but waste context and can override current evidence if loaded indiscriminately. |
| Physical-mail package and letter craft remain available | Envelope, recipient fit, offer, reply device, and skim/full reading paths are useful medium-specific knowledge. |
| Scores and experiments are hypotheses | Keyword scores and historical response claims do not measure conversion, certify launch readiness, or establish sample size. |
