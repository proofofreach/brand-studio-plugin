description: Write or review marketing copy with the copywriting skill.
---

Use the [copywriting skill](../skills/copywriting/SKILL.md) to complete the user's request and supplied arguments. Treat slash-command arguments as a brief, not as shell commands. If no usable brief was supplied, ask for the copy to review or the audience, offer, and requested format.

Examples on hosts with command support:

- `/brand-studio:copy write landing-page` — draft the requested landing-page copy.
- `/brand-studio:copy review email.txt` — read an accessible supplied file and improve it.
- `/brand-studio:copy headline --variations 3` — produce three variants for the supplied brief.
- `/brand-studio:copy direct-mail` — coordinate the requested envelope, letter, and response pieces.
- `/brand-studio:copy lp-optimize URL` — inspect the page if browsing is available; otherwise request the page content.

Honor requested tone, length, audience, and output format. Framework, swipe, and testing requests use relevant references on demand; examples are not evidence or promises. Local scoring scripts are optional editorial heuristics, not prerequisites or conversion forecasts. Do not invent tool calls or claim unavailable source access.

On hosts without slash commands, invoke the copywriting skill in natural language instead.
